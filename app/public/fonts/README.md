# Fonts

The `.ttf` files here are under the SIL Open Font License 1.1 (see `src/OFL.txt`), from [google/fonts](https://github.com/google/fonts) and IBM Plex. Archivo and Cormorant are static instances cut from the variable fonts. The `stroke/` single-line fonts came with [mexicat/pdoom-video](https://github.com/mexicat/pdoom-video); see that repo for their sources.

To add a font for a client, drop it here and add it to `DEFS` in `app/src/engine/type.ts`.
